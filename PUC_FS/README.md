# PUC_FS — Методы отбора признаков на основе Principled Uplift Curve

## Описание

Данная папка содержит разработку и исследование авторских методов отбора признаков на основе метрики **PUC (Principled Uplift Curve)** и каузального анализа. PUC представляет собой принципиальный подход к оценке uplift-эффекта, учитывающий специфику каузальных задач.

## Содержимое

| Файл | Описание |
|------|----------|
| `PUC.ipynb` | Реализация и сравнение 5 методов отбора признаков на основе PUC |
| `Causal_graph.ipynb` | Построение каузального графа и анализ причинно-следственных связей |

## Методы

### Метод 1: `puc_filter_selector`
Фильтрационный отбор признаков на основе PUC-метрики. Каждый признак оценивается индивидуально, признаки ранжируются по вкладу в PUC.

### Метод 2: Forward Stepwise Selection по PUC
Пошаговый жадный отбор признаков: на каждом шаге добавляется признак, максимизирующий прирост PUC. Позволяет учитывать взаимодействия между признаками.

### Метод 3: `puc_permutation_importance`
Permutation Importance на основе PUC: оценка важности признака путём измерения изменения PUC при перемешивании его значений.

### Метод 4: Гибридный каузально-PUC отбор
Комбинированный подход, объединяющий каузальный анализ (выявление причинно-следственных связей) с PUC-метрикой для отбора признаков, имеющих каузальное влияние на uplift.

### Метод 5: `PUCUpliftTree`
Модификация UpliftTree с использованием PUC в качестве критерия разбиения, с извлечением важности признаков из построенного дерева.

## Каузальный граф

В ноутбуке `Causal_graph.ipynb` строится каузальный граф с помощью алгоритма **PC** из библиотеки `causallearn`:
- Выявление причинно-следственных связей между признаками
- Определение конфаундеров и механизмов влияния
- Использование графа для информированного отбора признаков

## Схема эксперимента

1. Предобработка данных `fetch_lenta`
2. Реализация PUC-метрик и вспомогательных функций
3. Применение 5 методов отбора признаков
4. Оценка качества каждого метода по AUUC и PUC
5. Построение каузального графа и анализ связей
6. Сравнение всех подходов
