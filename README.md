# uplift_fs

Репозиторий для дипломной работы по теме **"Исследование методов отбора признаков в задачах Uplift-моделирования"**.

## Описание

Данный репозиторий содержит эксперименты по отбору признаков в задачах uplift-моделирования на датасете `fetch_lenta` из библиотеки `scikit-uplift`. 


## Структура репозитория

| Папка | Описание |
|-------|----------|
| [`EDA/`](EDA/) | Разведочный анализ данных (Exploratory Data Analysis) датасета fetch_lenta |
| [`Articles/`](Articles/) | Воспроизведение и адаптация методов отбора признаков из научных статей |
| [`FilterMethods/`](FilterMethods/) | Исследование фильтрационных методов отбора признаков из библиотеки `causalml` |
| [`ImportanceMethods/`](ImportanceMethods/) | Методы отбора признаков на основе важности (SHAP, Permutation Importance, UpliftTree) |
| [`PUC_FS/`](PUC_FS/) | Реализованные методы отбора признаков на основе Principled Uplift Curve (PUC) и каузального графа |

## Датасет

**fetch_lenta** — агрегированные данные о покупках клиентов сети супермаркетов "Лента", объединённые с информацией о проведённых SMS-рассылках. 

- **Записей:** ~687 000
- **Признаков:** 193
- **Целевая переменная:** `target` (0/1 — совершил ли клиент целевое действие)
- **Воздействие:** `treatment` (test/control — была ли рассылка)

## Основные этапы исследования

1. **EDA** — анализ распределений, пропусков, дисбаланса классов, корреляций
2. **Фильтрационные методы** — отбор признаков с помощью статистических тестов (ED, KL, Chi-square)
3. **Методы на основе важности** — отбор через SHAP-значения, Permutation Importance, Feature Importance из UpliftTree
4. **Методы из статей** — воспроизведение подходов из современных публикаций
5. **PUC-методы** — разработка и исследование методов на основе Principled Uplift Curve
