# FilterMethods — Фильтрационные методы отбора признаков

## Описание

Данная папка содержит исследование фильтрационных (filter) методов отбора признаков в задачах uplift-моделирования. Фильтрационные методы основаны на статистических тестах и не требуют обучения модели для оценки важности признаков.

## Содержимое

| Файл | Описание |
|------|----------|
| `Filter_methods.ipynb` | Исследование фильтрационных методов из библиотеки `causalml` |

## Методы

В ноутбуке реализованы и сравнены следующие фильтрационные методы из модуля `causalml.feature_selection.FilterSelect`:

### 1. ED Filter (Expected Difference)
Фильтр на основе ожидаемой разницы распределений признака между группами с положительным и отрицательным эффектом воздействия.

### 2. KL Filter (Kullback-Leibler Divergence)
Фильтр на основе дивергенции Кульбака-Лейблера между распределениями признаков для различных подгрупп.

### 3. Chi-Square Filter (χ²)
Фильтр на основе критерия согласия Пирсона (хи-квадрат) для оценки связи между признаком и uplift-эффектом.

## Схема эксперимента

1. Загрузка и предобработка данных `fetch_lenta` (см. [`EDA/`](../EDA/))
2. Применение фильтрационных методов для ранжирования признаков
3. Отбор топ-k признаков по каждому методу
4. Обучение T-Learner (CatBoostClassifier) на отобранных признаках
5. Оценка качества по метрике **AUUC** и **PUC** на train и test выборках
6. Сравнение результатов с baseline (все признаки)
