# EDA — Разведочный анализ данных

## Описание

Данная папка содержит ноутбук с разведочным анализом датасета `fetch_lenta` из библиотеки `scikit-uplift`. EDA проводится для понимания структуры данных, выявления проблем и подготовки к этапу отбора признаков в задачах uplift-моделирования.

## Содержимое

| Файл | Описание |
|------|----------|
| `EDA.ipynb` | Полный анализ датасета: загрузка, визуализация, статистики, выявление аномалий |

## Ключевые выводы EDA

1. **Дисбаланс воздействия:** 75% записей попали в тестовую группу (воздействие было), 25% — в контрольную
2. **Дисбаланс целевой переменной:** только ~10% клиентов совершили целевое действие
3. **Пропуски в данных:** присутствуют пропуски, которые заполняются значением `-100` (минимальное значение в датасете — 0)
4. **Категориальный признак:** единственный категориальный признак — `gender` (пол клиента). Пропуски заполняются `-1`, значения кодируются: Male → 1, Female → 0
5. **Дубликаты:** обнаружено 30 полных дубликатов, которые были удалены
6. **Удаление признаков:** на этапе EDA признаки не удалялись

## Предобработка данных

На основе EDA была сформирована следующая pipeline предобработки:

```python
# Кодирование пола
data['gender'] = data['gender'].map({'Male': 1, 'Female': 0})
data['gender'] = data['gender'].fillna(-1)

# Заполнение пропусков
data = data.fillna(-100)

# Удаление дубликатов
data = data.drop_duplicates()

# Разбиение на выборки с стратификацией по treatment и target
train_val_idx, test_idx = train_test_split(data.index, test_size=0.2, stratify=data[['treatment', 'target']])
train_idx, val_idx = train_test_split(train_val_idx, test_size=0.25, stratify=data.loc[train_val_idx, ['treatment', 'target']])
```

Данная предобработка используется во всех последующих экспериментах репозитория.
