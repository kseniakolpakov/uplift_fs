# ImportanceMethods — Методы отбора признаков на основе важности

## Описание

Данная папка содержит исследование методов отбора признаков, основанных на оценке важности признаков с помощью различных техник интерпретации моделей машинного обучения.

## Содержимое

| Файл | Описание |
|------|----------|
| `Importance_methods.ipynb` | Исследование методов отбора признаков на основе SHAP, Permutation Importance и UpliftTree |

## Методы

### 1. Отбор на основе SHAP-значений
- Вычисление SHAP-значений для обученной модели
- Отбор признаков со средним абсолютным SHAP-значением > 0
- Признаки с нулевой или отрицательной важностью исключаются

### 2. Отбор на основе Permutation Importance (PI)
- Перемешивание значений признака и измерение падения качества модели
- Отбор признаков с положительным Permutation Importance (PI > 0)
- Более устойчив к коррелированным признакам, чем встроенные метрики

### 3. Комбинированный отбор (SHAP > 0 & PI > 0)
- Пересечение множеств признаков, отобранных по SHAP и Permutation Importance
- Более консервативный подход, отбирающий только стабильно важные признаки

### 4. Отбор с помощью Feature Importance из UpliftTree
- Обучение UpliftTreeClassifier из библиотеки `causalml`
- Извлечение важности признаков, использованных при построении дерева
- Отбор признаков на основе их вклада в разбиения дерева

## Схема эксперимента

1. Предобработка данных `fetch_lenta` (см. [`EDA/`](../EDA/))
2. Обучение базовой модели (CatBoostClassifier) и uplift-модели
3. Вычисление важности признаков каждым из методов
4. Отбор признаков по порогу важности
5. Переобучение моделей на отобранных признаках
6. Оценка качества по метрике **AUUC** и **PUC** на train и test выборках
7. Сравнение числа отобранных признаков и качества моделей

## Метрика качества

Для оценки качества используется метрика **AUUC** (Area Under the Uplift Curve) и **PUC** (Principle Uplift Curve). Для каждого метода проводится оптимизация гиперпараметров с помощью `optuna`.
